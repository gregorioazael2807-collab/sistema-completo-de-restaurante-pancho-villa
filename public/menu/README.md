# Fotografías del menú

Los siete archivos llamados *-photo.jpg se generaron para Pancho Villa y se guardan localmente. No dependen de URLs externas ni contienen personas identificables. Se redujeron a un máximo de 1200 px y calidad JPEG 82; la interfaz los sirve con next/image, sizes, quality y carga prioritaria solo para la imagen principal.

Las imágenes identifican tacos, burritos, quesadillas, especialidades, entradas, postres y bebidas. Las ilustraciones SVG son recursos vectoriales secundarios y alternativas gráficas; la semilla del catálogo referencia las fotografías JPG.
